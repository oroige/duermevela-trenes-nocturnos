# Duermevela · Trenes nocturnos

Portada de una marca ficticia de trenes nocturnos con coche-cama entre Madrid, Barcelona, Lisboa, París, Milán y Zúrich.

Hecha con HTML, CSS y JavaScript, sin frameworks. Tipografías: Bodoni Moda y Hanken Grotesk (Google Fonts).

- Fotografías: [Unsplash](https://unsplash.com) · Vídeos: [Pexels](https://www.pexels.com), enlazados por URL.
- Marca, horarios, precios y datos de contacto son inventados.

Para verla en local, abre `index.html` o ejecuta `python -m http.server` en esta carpeta.
